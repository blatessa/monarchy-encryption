# monarchy-encryption

[![CI](https://github.com/blatessa/monarchy-encryption/actions/workflows/ci.yml/badge.svg)](https://github.com/blatessa/monarchy-encryption/actions/workflows/ci.yml)
[![Docs](https://github.com/blatessa/monarchy-encryption/actions/workflows/docs.yml/badge.svg)](https://docs.monarchy.run/monarchy-encryption/)

TPM disk unlock for [Omarchy](https://omarchy.org) laptops, for each laptop's own boot files, with a recovery key for IT.
Nobody types a disk passphrase at boot, so the login screen is where people sign in.

**Docs: <https://docs.monarchy.run/monarchy-encryption/>**. Packages are on the
[releases page](https://github.com/blatessa/monarchy-encryption/releases).
